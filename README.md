# 懒懒天气 · 会看天的树懒（Lazy Weather Sloth）

把 FoloToy AI Passport 变成一只会看天的树懒。根据窗外实时天气，它会切换 8 种萌态形象（晴 / 多云 / 阴 / 雨 / 雪 / 雷阵雨 / 雾霾 / 大风），屏幕上同时显示城市、当前温度，并送上一句 8 字治愈语录。按 OK 还能手动预览每一只树懒；把手机里的照片传上来，它就秒变随身小相框，多图自动轮播。

> 本仓库为「固件发布仓库」，只提供烧录固件 `merge.bin` 与使用方法，不含源代码。

## ⚙️ 烧录方法

`merge.bin` 是合并好的整片固件，**从地址 0x0 开始烧录**，一步到位，无需分步烧 bootloader/分区/应用。

**工具推荐：ESP‑Flash（Flash Download Tool）**（Windows）
1. 打开工具，芯片选择 **ESP32‑C3**；
2. SPIDownload 模式，把 `merge.bin` 添加到地址 **0x0**；
3. 连接开发板，选择串口，波特率 115200（对齐 flash 的 SPI 频率）；
4. 点击 START 烧录，完成后复位设备即运行。

**工具推荐：esptool**（命令行）
```bash
esptool.py --chip esp32c3 --port <串口> write_flash 0x0 merge.bin
```

> 首次刷机会覆盖原有固件。若之后想擦除所有数据（WiFi、城市、相册），可用 `esptool.py erase_flash`。

## 🔧 首次使用三步速通

1. **开机**：等待设备进入主界面；
2. **连 WiFi**：用手机蓝牙（BLE）连设备，写入 WiFi 名称和密码（见下）；
3. **选城市**：默认城市为合肥 / 上海 / 哈尔滨，可按下 / 上与物理按键切换，或用手机新增任意城市。

## 📱 连接 WiFi（手机蓝牙 BLE）

设备蓝牙名：**SLOTH‑WX**。任意支持 BLE 写入的工具都可用，推荐免费 App：**nRF Connect**（iOS / Android）或 **LightBlue**。

操作步骤：
1. 手机打开蓝牙，用工具扫描并**连接 SLOTH‑WX**；
2. 找到 **SSID 特征**，写入你家的 WiFi 名称；
3. 找到 **PASS 特征**，写入该 WiFi 的密码；
4. 设备会自动联网，并在连接成功后自动刷新一次天气；
5. 连接状态会通过 **STATUS** 特征实时通知到手机。

> 固件内置 4 个 WiFi 槽位，可记忆多组 WiFi，下次自动连接首次保存的那个。

## 🏙️ 修改与新增城市

城市通过蓝牙 BLE 用手机写入，支持任意城市（含国外城市）。三个特征：

| 操作 | 特征 | 写入内容 | 示例 |
|------|------|----------|------|
| **新增城市** | CITY_ADD | `城市名,纬度,经度` | `南京,32.06,118.80` |
| 切换已有城市 | CITY | 城市下标（0、1、2…） | `0` |
| 删除城市 | CITY_DEL | 城市下标 | `1` |

新增城市成功后会自动切换到该城市；城市列表与当前城市会保存在设备中，**重启后仍保留**，最多可保存 12 个城市。

> 手工输入城市需要用国内天气源可识别的方式，若使用 open‑meteo 则直接按经纬度查询，任意地点都可用。

## 🖼️ 上传照片（随身小相框）

设备支持手机 BLE 上传图像，变成多图轮播的相框：
1. 手机以 Web Bluetooth 连接 SLOTH‑WX；
2. 把图片转换成 240×320 的 RGB565 格式，经 `IMG_CTRL` / `IMG_DATA` 特征分块写入；
3. 上传完成后进入相册页，上 / 下键切图，OK 切换自动/手动轮播。

> 更稳妥的方式是通过 USB 数据线直连上传（if your device supports it），避免 BLE 偶发断连。

## ❓ FAQ

**Q：看不到城市中文名？**
A：设备字库覆盖了省会、直辖市、计划单列市及港澳台等 41 个主要城市的汉字；其他城市会以拼音显示，属正常。

**Q：国外城市能显示吗？**
A：能。新增时填 `城市名,纬度,经度`，设备按经纬度经 open‑meteo 拉取全球天气；但国内城市天气源（中国天气网）不覆盖国外城市，仅依赖境外源。

**Q：想恢复出厂？**
A：用 `esptool.py erase_flash` 擦除整片 flash，再重新烧 `merge.bin`。
